Projeto e desenvolvimento de sistemas web

Descrição e Professor

A disciplina de Desenvolvimento Web aborda os principais conceitos e tecnologias utilizados na construção de páginas e aplicações para a internet, incluindo HTML, CSS, JavaScript e conceitos de front-end e back-end.

Professor responsável: Lucas Francisco da Matta Vegi
